# Project instructions

Baca [docs/CODE_RULES.md](docs/CODE_RULES.md) sebelum mengubah kode, struktur, data, atau dokumentasi proyek.
Selalu cek dokumentasi resmi sebelum implementasi dan prioritaskan komponen shadcn-svelte jika komponen yang dibutuhkan tersedia.
Gunakan Tailwind secara mobile-first dengan token theme dan utility composition; tambahkan arbitrary value hanya untuk kebutuhan desain yang jelas.
Pertahankan struktur folder feature-based yang dijelaskan di dokumen; cari lokasi yang sudah ada sebelum membuat folder atau pola import baru.
Aturan itu berlaku untuk semua agent dan kontributor.
